# SingleTSCBaselines scenario data

This directory contains three data-only junction scenarios selected from the
upstream SingleTSCBaselines repository:

- `junction_scenarios/Beijing_Gaojiaoyuan`
- `junction_scenarios/Chengdu_Guanghua`
- `junction_scenarios/Tianjin_zhijingdao`

The package includes network, route, detector, and signal-definition files.
It does not include a SUMO/TraCI runner, signal controller, generated
trajectories, or optimization results. Preserve the terms in `NOTICE.md` and
cite the upstream source listed in the repository-level `CITATIONS.md`.
